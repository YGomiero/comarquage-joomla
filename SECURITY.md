# Security

For ordinary support, use GitHub issues. Never attach `configuration.php`, database dumps, passwords, tokens or personal data.

For a security issue, use the repository's private vulnerability reporting feature if available. Otherwise send a minimal report to the public maintainer contact listed in the package manifest, without credentials or exploit data involving other people's systems. Do not disclose an unpatched vulnerability in a public issue.

Supported release line: 1.x on Joomla 6.x / PHP 8.3+. Keep Joomla, PHP and Distro patched. Only trusted administrators should configure local file sources or custom CSS themes. Imports accept official HTTPS remote sources; custom XML should be treated as untrusted input even in local mode.

FR : ne publiez aucun identifiant ni fichier de configuration dans les tickets. Réservez les sources locales et les thèmes CSS aux administrateurs de confiance. Maintenez Joomla, PHP et Distro à jour.
